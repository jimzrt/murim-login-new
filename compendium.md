Below is a **working terminology compendium for translating *Murim Login* from Korean into English**, using the long-running unofficial manhwa terminology as the house style. I am deliberately choosing **one preferred rendering** rather than cataloguing competing translations.

The unofficial English manhwa currently runs through the Season 3 endpoint around chapter 250/251, so this gives a substantial terminology base. ([Asura Scans][1]) The Fandom character, organization, skill, and location indexes are useful cross-checks because many entries explicitly trace their terminology to individual webtoon chapters. ([Murim Login][2])

# 4. Martial cultivation ranks

This is one of the most important consistency areas.

Use this hierarchy:

| Korean | Preferred English |
| ------ | ----------------- |
| 삼류     | **Third Rate**    |
| 이류     | **Second Rate**   |
| 일류     | **First Rate**    |
| 절정     | **Peak**          |
| 초절정    | **Supreme Peak**  |

In full prose:

| Korean construction | English                                   |
| ------------------- | ----------------------------------------- |
| 삼류 무인               | **third-rate martial artist**             |
| 이류 무인               | **second-rate martial artist**            |
| 일류 무인               | **first-rate martial artist**             |
| 절정고수                | **Peak master** / **Peak martial artist** |
| 초절정고수               | **Supreme Peak master**                   |

This mapping matters because the system explicitly treats reaching **First Rate** as a realm-stage requirement, and Jin Taekyung's status later progresses through Peak to **Supreme Peak Martial Master**. ([Murim Login][10]) The Korean source likewise describes Taekyung as starting at 삼류, reaching 일류, then 절정, and approaching 초절정. ([Namu Wiki][3])

Do **not** casually replace **Supreme Peak** with a generic cultivation-fiction term such as “Transcendent” when translating the manhwa's 초절정. Maintaining this ladder is more important than literal variation.

# 16. Translation house rules

For future Korean → English *Murim Login* translation, apply these consistently:

1. **Never re-romanize an established character.** Use **Jeok Cheongang**, **Jin Mukyung**, **Cheongpung**, **Hyuk Mujin**, etc., even if another transliteration could be defended linguistically.
2. **Translate martial titles, don't romanize them.** 화왕 is **Fire King**, 검성 is **Sword Saint**, 진천검 is **Heaven Shaking Sword**.
3. **Preserve the established realm ladder.** 삼류 → **Third Rate**, 이류 → **Second Rate**, 일류 → **First Rate**, 절정 → **Peak**, 초절정 → **Supreme Peak**.
4. **Use “qi” for the Murim energy system.** Use **mana** in the modern Hunter setting where the Korean/context treats it as mana.
5. **Use “Murim” as an established setting term.** Don't repeatedly replace it with “martial arts world.”
